# Фото формы — как снимать, загружать и разбирать

Страница «Фото» в приложении (`portal/photos.html`). Загрузка, выравнивание и сохранение — **прямо в приложении**, без
Python и интернета: библиотеки лежат в `portal/vendor/`. Фото — только на этом Mac, в git не попадают.
Код: `portal/photos_core.js` (логика: позы, медианы, выравнивание; тесты — `desktop/test/portal_photos.test.js`),
`portal/photos_app.js` (HEIC, поиск фигуры MediaPipe, запись в папку, окно загрузки), `portal/photos_fs.js` (файлы через приложение).

**Где лежат фото** — папка `photos/` в папке данных (по умолчанию `~/Documents/SEL/data/photos`; ниже — `data/photos`):

| что | где |
|---|---|
| оригинал как есть (HEIC/JPEG, байт в байт) | `originals/ГГГГ-ММ-ДД_<поза>.<heic/jpg>` |
| выровнено: один масштаб по росту — подгонка по многим точкам к шаблону позы; наклон выпрямлен, подошвы на одной линии, корпус по центру, 3330×5470 | `aligned/ГГГГ-ММ-ДД_<поза>.jpg` |
| оригинал в JPEG для показа (Chrome не открывает HEIC), 2400 px | `view/…jpg` |
| превью для ленты | `thumbs/…jpg` |
| индекс (дата, поза, точки фигуры) — пишет страница, руками не править | `photos.js` |

Позы: `front` спереди, `side` сбоку справа (правым боком к камере), `side_left` сбоку слева (левым боком; по желанию),
`back` сзади, `back_flex` спина-бицепс, `front_flex` бицепс. Кнопки поз на странице — только для тех, что есть в папке.

## Пользователю: как снимать (раз в месяц, первая суббота)

- **Утром, до еды**, после туалета; тот же коридор, тот же верхний свет (без солнца из окна)
- Телефон на одной точке и высоте (полка/штатив на уровне пупка), таймер 3–10 с; стоять на метке на полу
- **В полный рост, со стопами в кадре**
- Расслабленно, живот **не втягивать**
- **Ровно 5 снимков в этом порядке:**
  1. спереди — руки вдоль тела
  2. сбоку — правым боком к камере
  3. сзади — руки вдоль тела
  4. сзади — бицепсы (руки вверх, согнуты)
  5. спереди — бицепсы
- Если снимок не удался — удалить его на телефоне и переснять, чтобы в серии осталось ровно 5

## Пользователю: как загрузить

1. «Фото» на Mac → выделить снимки серии → **Файл → Экспортировать → Экспортировать немодифицированный оригинал…** в любую
   папку (например, «Загрузки»). Можно и AirDrop с телефона.
2. Приложение → «Фото» → **«Загрузить фото»** (или перетащить снимки на страницу).
3. Проверить дату и позы → «Сохранить». Позы определяются по фигуре на снимке (руки вверх, боком, лицом или спиной).
   Если поза снята несколько раз — **дубли** подсвечены: оставлен последний, остальные не сохранятся; лучше другой —
   «Оставить этот» под ним. **Клик по снимку** — оригинал во весь экран (клик — 100%, ← → — между дублями,
   «Оставить этот» прямо там, Esc — закрыть). **Уже загруженные** раньше снимки (тот же файл — по отпечатку SHA-256, или тот же кадр в другом
   формате — по времени съёмки до секунды) помечены «уже загружен» и повторно не сохраняются
4. Снимки сохраняются в `data/photos` сами — папку выбирать не нужно (её задаёт приложение).
5. Для разбора с Claude — написать «загрузил фото».
6. **Удалить снимок:** в сравнении «Рядом» под снимком «удалить снимок» → подтвердить; из папки удаляются оригинал и все копии

## Claude: порядок разбора

1. **Проверить, что легло:** `ls data/photos/originals data/photos/aligned | grep <дата>` — 5 поз; по индексу
   (`data/photos/photos.js`) поле `kp: null` = фигура не найдена (нет выровненной версии), `by`: `точки` — норма (подгонка по многим точкам; нужно ≥3 снимков позы), `силуэт` — снимков
   позы мало, `рост` / `корпус` — к тому же силуэт неполный; `th` — на сколько выпрямлен наклон (радианы); `feet_cut` — стопы у края или обрезаны
2. **Позы глазами:** посмотреть выровненные новой серии (Read `data/photos/aligned/<дата>_*.jpg` или лист из уменьшенных
   копий через `sips -Z 600` в scratchpad). Если поза перепутана — попросить пользователя загрузить серию заново с верной
   позой и галочкой «заменить существующее» (имена файлов в папке руками не переименовывать — индекс не узнает)
3. **Сравнить:** новая серия против прошлой и против самой первой, позы front, side, back_flex — выровненные из
   `data/photos/aligned/`. Смотреть: плечи/верх спины, руки, **живот сбоку**, бока сзади. Учитывать свет и время
   съёмки/еду
4. **Записать:**
   - строка в `data/photo_notes.csv` (`date,note` — коротко, что изменилось; на глаз, без «процентов жира»)
   - если вывод поменялся — `photos_summary` в `data/meta.json`
5. Заметки и вывод попадут на страницу «Фото» при следующем открытии приложения (оно пересобирает `data/data.js`)
6. Сказать пользователю коротко, что видно: заметки появятся, когда он откроет «Фото» в приложении

## Если что-то не так

- **Как выравнивается** (`PhotosCore.alignAll`): рост человека не меняется — по нему и масштаб, только по высоте (ширины плеч и
  талии — то, что сравниваем, по ним не равняем). 1) Наклон: ось «щиколотки → плечи» — вертикально (до ±5°). 2) Масштаб и
  высота — подгонка по 9 точкам (макушка по силуэту, глаза, уши, плечи, таз, колени, щиколотки, пятки, подошвы по силуэту)
  к шаблону позы: медианы по всем снимкам позы, рост в шаблоне = 4300 px; шумные точки весят меньше, выбросы (пышные волосы,
  сбойный таз) отбрасываются. 3) Центр корпуса по силуэту — в центр. Проверка на 65 снимках (11.2026): точка вне подгонки
  гуляет по высоте в среднем на 21 px против 27 px у масштаба только по силуэту; сбоку 31 против 38. Не исправить: перспективу
  (разное расстояние до камеры), осанку и стойку — только съёмка с одной метки
- **Новые снимки** подгоняются к шаблону из уже лежащих в папке; старые при этом не перерисовываются — «Пересобрать всё», если
  накопилось много новых серий

- **Пересобрать всё** (поменялся алгоритм, потерян индекс, руками положили оригиналы в `originals/` с именами
  `ГГГГ-ММ-ДД_<поза>.<ext>`): внизу страницы «Пересобрать всё» — заново выравнивает все снимки (65 штук ≈ 1 мин)
- **«фигура не найдена»** — снимок сохранён без выравнивания; посмотреть фото, при необходимости попросить переснять
- **Стопы у края кадра или обрезаны** — подошвы по силуэту не найти: масштаб по «нос–щиколотки» (или корпусу) в пересчёте на
  силуэт по другим снимкам, линия пола — по оценке; точность ниже. Страница пишет об этом. Попросить снимать с запасом пола под стопами
- **Страница из файла в браузере, без приложения** (для разработки): загружать можно только в Chrome или Edge — при первой
  загрузке страница попросит выбрать папку данных (или проект с `data/`) и сама создаст в ней `photos/`; Safari и Firefox
  только показывают. Chrome не видит «Документы» — Системные настройки → Конфиденциальность и безопасность → Файлы и папки →
  Google Chrome → «Папка „Документы“» (менять — только пользователь)
- **Обновить библиотеки** (`portal/vendor/`): поменять версии в `scripts/vendor_fetch.js` → `node scripts/vendor_fetch.js`
  → проверить загрузку серии и «Пересобрать всё»; `--check` сверяет файлы с хэшами
- **Проверка без окна выбора папки** (для Claude): headless Chrome + тестовая «папка» поверх локального http-сервера,
  `PhotosApp.useDirectory(handle)`; выбор папки — подменой `window.showDirectoryPicker` (так проверялась загрузка при переносе
  в браузер; дизайн и план той работы — в истории git, коммит bfd7f82)
