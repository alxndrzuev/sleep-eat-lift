# Профили: план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** несколько человек в одном SEL: папка данных — корень с `profiles/<id>/`, перенос данных 1.x в профиль,
первый запуск с именем профиля, переключение/создание/переименование/удаление, вес вручную на «Фото».

**Architecture:** новый модуль `desktop/profiles.js` (чистые функции над файлами: список, создание, перенос). В `main.js`
корень (`ROOT`) и папка текущего профиля (`DATA`) — раздельно; весь прежний код получает `DATA` как раньше.
Переключение = новый `DATA` + новый `updater` + перезагрузка окна. Страницы о профилях знают только через меню
(`nav.js`), «Настройки» и экран имени `portal/profile.html`.

**Tech Stack:** Electron, Node 26 (`node --test`), страницы — обычные `<script>` (тесты — `test/_portal.js`, `RENDER=1`).

**Spec:** `docs/superpowers/specs/2026-11-23-profiles-design.md`

## Global Constraints
- Схема CSV не меняется; писать CSV — только `store.js`.
- Версия при выпуске — 2.0.0 (пункт в «Не выпущено» → «Изменено»); выпуск — не в этом плане.
- Перенос: rename, не копирование; знакомое — CSV из схемы, `sync.json`, `photos/`, `docs/`, `README.md`,
  `secrets/fatsecret.json`, `secrets/whoop.json`; остальное в корне не трогать.
- Ключи приложений (`*_app.json`) — в корневом `secrets/`; токены — в `profiles/<id>/secrets/`.
- Удаление профиля — в Корзину (`shell.trashItem`); последний нельзя.
- Вес вручную — во всех профилях, на дату серии, `store.upsert` только `weight_kg` (без `note`); `fatsecret.js` не трогать.
- Текст из файлов/имён профилей — в innerHTML только через `esc()`.
- Каждый новый модуль, который подключает `main.js`, и новые файлы данных (`root_readme.md`) — в `build.files`.

## Review Focus
1. Прерванный перенос (упал посреди) → следующий запуск доводит без вопросов, ничего не теряется. — Task 2.
2. Имя профиля с кириллицей, пробелами, `/`, `..`, эмодзи, пустое после обрезки → id безопасный (`[a-z0-9-]`), не уходит
   из `profiles/`; имя в меню экранировано. — Task 1, Task 5.
3. Переключение во время обновления/входа/записи фото → отказ с понятной причиной, данные не смешиваются. — Task 4, Task 5.
4. Вес «80,1», « 80.1 », «abc», «0», «500» → 80.1 / 80.1 / ошибка / ошибка / ошибка. — Task 6.
5. Корневые CSV после переноса: пустые (только заголовок, их создаст 1.x) → тишина; со строками → предупреждение. — Task 2.

### Task 1: `desktop/profiles.js` — список, id, создание, переименование, выбор

**Files:** Create `desktop/profiles.js`, `desktop/test/profiles.test.js`; Modify `desktop/package.json` (`build.files`).

**Interfaces — Produces:**
- `slug(name: string, taken: Set<string>) -> string` — транслитерация ru→lat (своя таблица), нижний регистр, всё
  кроме `[a-z0-9]` → `-`, схлопнуть/обрезать `-`, до 32 символов; пусто → `profile`; занято → `-2`, `-3`…
- `cleanName(name) -> string` — trim, схлопнуть пробелы; пусто или > 40 символов → throw `Error('Имя: от 1 до 40 символов')`.
- `list(root) -> [{id, name, created, migrating}]` — папки `profiles/*` с читаемым `profile.json`, по имени (`localeCompare('ru')`).
- `dir(root, id) -> string` — `profiles/<id>`; id не `^[a-z0-9-]+$` → throw.
- `create(root, name, today) -> {id, dir}` — папка, `profile.json` `{name, created: today}`, `store.init(dir)`.
- `rename(root, id, name) -> void` — меняет только `name`.
- `pick(root, wanted) -> id|null` — `wanted`, если есть в `list`, иначе первый, иначе null.
- `photoCount(dir) -> number` — число файлов в `photos/originals`.
- `remove(root, id, trash: (path) => Promise) -> Promise` — последний профиль → throw `Error('Последний профиль удалить нельзя')`.

- [ ] **Step 1: тесты** `profiles.test.js`: `slug('Александр', new Set()) === 'aleksandr'`; `slug('Иван Петров', new Set(['ivan-petrov'])) === 'ivan-petrov-2'`;
  `slug('../..', new Set()) === 'profile'`; `slug('😀', …) === 'profile'`; `cleanName('  Мария  С. ') === 'Мария С.'`; `cleanName(' ')` бросает;
  `create` + `list` (два профиля, сортировка «Борис» < «Иван»); `rename` не меняет id и папку; `dir(root, '../x')` бросает;
  `pick(root, 'nope')` → первый; `remove` последнего бросает, `remove` другого вызывает `trash` с `profiles/<id>`.
