# Фото: окно «Как снимать» перед загрузкой — короткий дизайн

Дата: 27.11.2026. Страница «Фото» (`portal/photos.html`).

**Зачем:** правила съёмки и поддерживаемые позы видны только в документе проекта; в приложении — одна строка в пустой
странице. Тот, кто снимает (пользователь или клиент тренера), должен видеть их в момент загрузки.

**Что:** «Загрузить фото» → окно «Как снимать»: схематичные фигурки поддерживаемых поз (спереди; сбоку — руки любые;
сзади; спина-бицепс; бицепс; «сбоку слева — по желанию»), две схемы кадра (в полный рост — лучше; без головы или стоп —
примется, если плечи и колени в кадре), короткие правила съёмки → кнопки «Отмена» и «Выбрать файлы» (открывает выбор).

**Не цели:** отдельная страница, настоящие фото в примерах, выгрузка наружу (PDF/картинка).

**Подходы:** окно в существующем модальном (выбран — порядок «нажал → правила → файлы», как попросил пользователь);
отдельная страница (ломает этот порядок); настоящие фото (чужие личные снимки, а нужны схемы).

**Решено мной:** окно — при каждом нажатии (один лишний клик); перетаскивание снимков на страницу — сразу, без окна;
фигурки — SVG кодом (`portal/photos_guide.js`, без DOM, `currentColor` — светлая и тёмная тема, без интернета); пустая
страница отсылает к кнопке.

**Проверка:** тест — у каждой позы своя фигурка (спереди ≠ сзади, слева — зеркало справа), в окне все позы, про плечи и
колени, кнопки; страница подключает `photos_guide.js` и открывает окно по кнопке; `RENDER=1 npm test`; глазами в SEL.
