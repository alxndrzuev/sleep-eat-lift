# «Что нового»: как вернуться назад

**Зачем.** Страница «Что нового» открывается из «Настроек», из меню «Справка» и кнопкой «Вся история» в окне после
обновления — с любой страницы. Обратного пути нет: меню наверху ничего не подсвечивает, «Назад» в приложении нет вообще.

**Подходы.**
- А. «← <откуда пришёл>» над заголовком — сделали первым, но перегружает интерфейс (решение пользователя 22.11).
- **Б. Только крестик справа сверху, без меню разделов** — выбрано: понятнее «закрыть страницу»; куда вернёт — в подсказке.
- В. Вся история во всплывающем окне вместо страницы — больше переделки (меню «Справка» → окно через IPC), ради того же.

**Как.**
- Крестик ✕ справа в заголовке (над правым краем карточки); меню разделов на странице нет. Возвращает на последнюю
  открытую страницу меню — её запоминает nav.js в `sessionStorage` (`navLast`): `document.referrer` у схемы app:// пустой.
  Клик — `history.back()` (как ⌘[); не знаем, откуда пришли, — на «Сводку». Куда вернёт — в подсказке крестика.
- Esc на странице — то же, что клик.
- Меню «Справка → Что нового» на самой странице истории ничего не делает (иначе «назад» вело бы на неё же).
- Во всём приложении: «Вид → Назад ⌘[» и «Вперёд ⌘]» (история окна Electron).
- Название страницы по имени файла — `Nav.title(page)` в nav.js (один список пунктов меню); «Что нового» туда не входит.

**Не делаем.** Ссылку «← …», всплывающее окно с полной историей, свайпы трекпада.
