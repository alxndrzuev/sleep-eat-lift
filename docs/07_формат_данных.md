# Папка данных — всё личное

Где лежит: папка, выбранная в приложении «Здоровье» (по умолчанию — `~/Documents/Здоровье/data`), без git.
Программа (`portal/`, `desktop/`, `scripts/`) личного не содержит. В папке:
- `*.csv` — вся история (описание ниже); пишет приложение (FatSecret, Whoop, цели, алкоголь) и пользователь
- `meta.json` — план, «хорошая неделя», журнал недель, приоритеты, вывод по фото, `alcohol_from`
- `data.js` — сырые таблицы для страниц (`const RAW`), пишет приложение
- `photos/` — фото формы (см. `docs/06_фото_инструкция.md`)
- `secrets/` — ключи приложений и токены FatSecret, Whoop; в чате не показывать
- `docs/` — личные документы: профиль и цели, план, журнал недель, решения, анализ
- `inbox/` — черновики разборов, выгрузки, скриншоты
- `logs/` — прежние логи

## CSV — полная история

Правила:
- Одна строка = одна запись. **Только дописываем**, старое не удаляем (исправлять ошибки можно)
- Даты `YYYY-MM-DD`, десятичный разделитель — точка, пустая ячейка = нет данных
- Кодировка UTF-8, разделитель запятая, переводы строк LF; если в тексте нужна запятая — брать поле в кавычки
- Колонки заданы в `SCHEMA` (`scripts/lib.py`) — скрипты проверяют заголовок; при изменении колонок править и там, и здесь. Новые колонки — только в конец: старые файлы без них читаются, колонка появится при следующей записи
- Из кода писать только через `lib.write` / `lib.upsert`

| Файл | Колонки | Откуда | Как часто |
|---|---|---|---|
| `nutrition_daily.csv` | date, kcal, protein, fat, carbs, fiber | приложение: API FatSecret (при запуске и кнопкой) | ежедневно |
| `body.csv` | date, weight_kg, waist_cm, bodyfat_pct, note | вес — приложение из FatSecret (note «FatSecret»); талия — от пользователя (в чате) | ежедневно / раз в неделю |
| `whoop_daily.csv` | date, recovery (%), hrv (мс), rhr, spo2 (%), skin_temp (°C), strain, kcal (расход за день), steps (шаги за день), sleep_h, deep_h, rem_h, light_h, awake_h, sleep_perf (%), sleep_eff (%), resp_rate, bed / wake (отбой и подъём, местное ЧЧ:ММ), note | API Whoop, приложение (при запуске и кнопкой); день = день после ночного сна | ежедневно |
| `whoop_workouts.csv` | id, date, start, sport, duration_min, strain, avg_hr, max_hr, kcal, z0_min…z5_min (минуты в пульсовых зонах) | API Whoop | ежедневно |
| `supplements.csv` | start, end, name, dose, timing, purpose, note | от пользователя; только изменения: начал / бросил / сменил дозу. Пустой `end` = принимает сейчас | при изменении |
| `checkins.csv` | date, feel, energy, stress, sleep_quality (все 1–10), note | от пользователя на разборе (раньше — кнопки Telegram) | раз в неделю |
| `labs.csv` | date, marker, value, unit, ref_low, ref_high, note | анализы крови и пр. | при сдаче |
| `targets.csv` | start, kcal, protein, fat, carbs, note | цели по питанию — **задаёт пользователь в чате**: строка = новая цель с даты `start`, действует до следующей | при смене цели |
| `goal_weight.csv` | date, goal_weight_kg, note | целевой вес — **задаёт пользователь в чате**; строка = новая цель с даты `date` | при смене цели |
| `alcohol_check.csv` | date (утро), hrv_dev_pct, rhr_dev, temp_dev, strength (оценка по сигналу: мало / умеренно / много), kind (алкоголь?/болезнь?), status (?/да/нет), note | приложение (`desktop/alcohol.js`) после обновления Whoop: HRV −25%+ и пульс +5+ к медиане 30 дней; status — ответ пользователя на «Восстановлении» | ежедневно |
| `workout_labels.csv` | id (тренировки Whoop), date, start, label (strength / squash / cardio / other / none = не тренировка), note | от пользователя (раньше — кнопки Telegram); метка главнее вида из Whoop | по необходимости |
| `photo_notes.csv` | date (серия фото), note | что видно на фото по сравнению с прошлыми (оценка на глаз) | раз в месяц |
| `events.csv` | start, end, type, description, level (для алкоголя: мало / умеренно / много; пусто — не указано) | болезнь, травма, поездка, алкоголь, стресс, перерыв в тренировках… | по событию |

Типы событий в `events.csv`: `болезнь`, `травма`, `поездка`, `алкоголь`, `стресс`, `перерыв`, `другое`.
