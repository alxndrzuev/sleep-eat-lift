# Безопасность / Security

Нашли уязвимость — пожалуйста, не открывайте публичный issue. Напишите через
[GitHub Security Advisories](https://github.com/alxndrzuev/sleep-eat-lift/security/advisories/new)
(«Report a vulnerability»): что за проблема, как воспроизвести, на какой версии.

Found a vulnerability? Please don't open a public issue — report it privately via
[GitHub Security Advisories](https://github.com/alxndrzuev/sleep-eat-lift/security/advisories/new).

Как устроена защита данных — раздел «Безопасность и приватность» в [README](README.md).
Поддерживается только последняя версия приложения.
