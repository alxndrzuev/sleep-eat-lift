# Папка данных SEL — профили

Здесь лежат данные приложения SEL (sleep · eat · lift) для нескольких человек. Каждый человек — отдельный профиль
со своей папкой. Файл написан для того, кто будет читать папку (человека или LLM); приложение перезаписывает его
при запуске, поэтому править его бесполезно.

## Что где
- `profiles/<id>/` — один профиль = один человек. Внутри — его питание, вес, сон, тренировки (CSV), фото формы,
  личные документы и свой `README.md` с описанием всех файлов. Имя человека — в `profiles/<id>/profile.json`
  (`name`); `<id>` — латиница из имени при создании, при переименовании не меняется.
- `profiles/<id>/secrets/` — ключи доступа этого человека к FatSecret и Whoop. **Не читать, никуда не пересылать и не показывать.**
- `sel.json` — служебное: формат папки (`format`) и какая версия SEL открывала её последней (`app`). Версия SEL,
  которая знает формат ниже, такую папку не открывает.
- `secrets/` — ключи самих приложений FatSecret и Whoop (не человека). **Не читать, никуда не пересылать и не показывать.**
- Другие файлы в этой папке приложение не создаёт и не читает. CSV прямо здесь (рядом с `profiles/`) — старые данные
  версий до 2.0 или копия; приложение их не показывает и при запуске предлагает перенести в профиль.

## Как читать
Данные разных людей не смешивайте: выводы — по папке одного профиля. Начните с `profiles/<id>/README.md`.
